# Vane Workbench (Phase 1)

Built-in extension for the Vane Code—OSS fork.

Provides:

- Activity bar container **Vane**
- Views: Agent, Wallets, Transactions (placeholders)
- Status bar: model, agent, chain, wallet, mode, vault (placeholders)
- Commands: `vane.openAgent`, `vane.openWallets`, `vane.openTransactions`
- Settings: `vane.*`

**Out of scope:** vault, private keys, signing, swaps, bridges, Live execution.
